# 用例 Excel 骨架

建议工作表：`TestCases`。脚本 `scripts/gen_testcase_xlsx.py` 会生成以下字段：

| 字段 | 说明 |
|---|---|
| 用例ID | 唯一标识 |
| 模块/功能 | 被测对象 |
| 状态节点 | 生命周期节点 |
| 前置条件 | 数据与环境 |
| 操作步骤 | 可执行步骤 |
| 预期结果 | UI、数据、同步与回滚 |
| 测试类型 | 主链路/分支/边界/回归等 |
| 打断层级 | L1-L7 或无 |
| 影响面 | 8 类对象，可多选 |
| 风险级别 | S1-S4 或自定义 |
| 优先级 | P0-P3 |
| 备注 | 弱网建议、假设、证据 |
