## 待补后扩展方向

材料补齐后，按以下顺序回填，把骨架扩展成完整用例：

1. 每个行为拆原子节点，逐节点走七问；
2. 命中节点补 L1-L7 打断；
3. 逐节点扫 8 类影响面；
4. 补边界值（0 / 1 / 上限 / 上限+1 / 极大 / 负数 / 空）；
5. 有 UI 产出的节点补 UI 断言（icon 资源 / 显隐 / 布局文案 / 状态视觉）。
