# 风险与优先级分级标准

## 风险级别（S1-S4）

| 级别 | 名称 | 判定标准 |
|---|---|---|
| S1 | 致命 | 经济/充值/公平性错误，或主链路不可用，造成不可逆损失或大面积影响 |
| S2 | 严重 | 主功能失败、数据错误；有绕过手段或低频触发 |
| S3 | 一般 | 次要功能异常、边界处理不当 |
| S4 | 轻微 | 体验/文案/UI 瑕疵 |

> S1 只在缺陷影响范围、不可逆性和业务损失达到致命标准时定级，不要仅因"体验差"定 S1。详见 [s1-game-scenarios.md](s1-game-scenarios.md)。

## 优先级（P0-P3）

| 级别 | 判定标准 |
|---|---|
| P0 | 阻塞主链路或 S1 缺陷相关，必测 |
| P1 | 核心功能主路径 + 高频打断 |
| P2 | 分支/边界/低频路径 |
| P3 | 体验优化、极端边界（可抽样） |
