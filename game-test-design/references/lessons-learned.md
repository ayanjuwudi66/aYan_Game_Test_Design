# 历史教训库

集中收录执行中踩过的坑，正文只留规则性结论，故事的"何时何项目"沉淀在此。

## 图片识别

- **2026-09-02 偷菜**：首次读图被 "model does not support images" 拦截，误判为模型不支持、几乎放弃，整份用例差点漏掉图内规则；随后同样文件、同样工具直接读，14 张全部成功。**结论：一次失败是调用方式/间歇性问题，不是能力问题；读图失败必须先重试换方式，不得直接判"不支持"。**

## 输出格式

- **前置条件混进操作步骤**（旧写法 `前置：<条件>。1. …`）：一列两责，执行人分不清"要准备什么"和"要做什么"，也无法按前置批量准备数据。**结论：前提条件独立成列，操作步骤只写动作。**
- **多条内容挤一行靠列宽折行**：序号被折断，执行人看不出总共几步。**结论：单元格内用换行符逐条断开（脚本 `cell_break()` 自动处理）。**
- **列序**：优先级是执行前看的排期依据、结果是执行后填的产出，结果应置末列，执行时视线一路向右到底打勾。

## 运行环境

- **2026-09-03 读非 C 盘 xlsx**：sheet-agent 子代理与 `resolve_local_excel` 均无法访问 Windows 盘符路径（`F:\...` 报 INVALID_LOCAL_PATH；`/f/...` 被错误解析为 `c:\f\...` 后报 LOCAL_PATH_NOT_FOUND）。**结论：xlsx 位于非 C 盘（或任何 Windows 盘符路径）时跳过 sheetagent 委托，直接用 python + openpyxl 全量读取（合并单元格、批注一并读），并用 zipfile 解包 `xl/media/*` 查内嵌图；该工具链仅能解析其运行环境内以 `/` 开头且真实存在的路径。**

## UI 断言

- **只测成熟态漏掉成长态；只测未变异漏掉变异后新增字段标签。** 结论：UI 元素多态/多变体必须逐变体断言。
- **文字里"显示 XX icon"对应的小图被当"装饰"跳过。** 结论：独立小 icon 图集必须建索引并对应到用例。
