# 影响面横向扫描

七问沿时间轴推进；影响面横向回答“对谁变了”。每个节点（包括打断节点）对以下对象逐类回答四问：

1. 是否受影响？（受影响/不受影响/未定义；未定义即补充项）
2. 影响是否同步？（本地、服务端、各客户端）
3. 阵营/权限过滤是否正确？
4. 异常时能否干净回滚？

| 对象 | 典型风险 |
|---|---|
| 自身 | 状态残留、重复扣减、CD 错误 |
| 队友 | 增益未生效、误伤、视角缺特效 |
| 敌对玩家 | 伤害漏判、表现与服务器不一致 |
| 中立单位 | 技能错误生效、仇恨异常 |
| 环境场景 | 破坏未同步、碰撞/寻路未更新 |
| 观战/旁观者 | 看不到或泄露战争迷雾信息 |
| 服务器全局 | 结算、经济、排行榜、赛季未更新 |
| AI/召唤物 | 未继承 Buff、响应错误 |

不要默认所有对象都受影响；对“不受影响”也记录依据，对“未定义”转入 Part B。
