# L1-L7 打断分层

L1-L7 是通用框架，必须按被测功能实例化：

| 层级 | 定义 | 例子 |
|---|---|---|
| L1 | 动作互斥 | 投掷中切枪；换弹中开火；施法中位移 |
| L2 | 状态强制 | 死亡、眩晕、击退、冰冻、沉默、石化 |
| L3 | 场景切换 | 结算、退出、掉线重连、切场景、跨服 |
| L4 | 资源约束 | 冷却中、弹药/蓝量/体力/道具/货币不足 |
| L5 | 交互抢占 | 拾取、开门、上下载具、救人、对话、开背包 |
| L6-a | 系统中断 | 切后台、来电、锁屏、权限弹窗、低电量 |
| L6-b | 网络异常 | 断网；高延迟、丢包、带宽受限、抖动 |
| L7 | 输入异常 | 连点、多指、快速切换、外设断连、误触、长按/滑动冲突 |

每个打断场景至少验证：当前状态、已扣资源、客户端表现、服务端判定、恢复路径、残留清理。高 ping 下重复 L1-L7，关注本地已播特效/扣资源而服务端失败时的干净回滚。L1/L2/L5 备注统一写“建议叠加弱网复测”。

### 品类实例化提示

- FPS/TPS：换弹/投掷/开镜/载具互斥，击倒与重连。
- MOBA：前摇被控制、位移抢占、死亡/复活、技能资源不足。
- RPG：吟唱、持续技能、仇恨切换、场景传送、背包占满。
- SLG：建造队列抢占、跨天/跨服、资源不足、并发领取。
