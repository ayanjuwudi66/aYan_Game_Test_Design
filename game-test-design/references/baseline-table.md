# 循环截断基线

无天然终态的循环使用边界截断：先按功能类型取推荐 N/T，再请用户采纳；不采纳则由用户指定。

| 类型 | N | T |
|---|---:|---:|
| 高频循环动作 | 1000 次 | 300s |
| 中频循环动作 | 100 次 | 120s |
| 长按/持续按压 | — | 300s |
| 整局循环 | 20 局 | 1800s |
| 概率型循环 | 1000 次 | — |
| 资源产出/消耗循环 | 500 次 | — |
| 挂机/放置类 | — | 3600s |

截断后必查（功能正确性）：数值溢出、状态机漂移。
性能/资源类异常（帧率、内存、对象池、日志与网络包量）→ 只记录，转交性能专项。
